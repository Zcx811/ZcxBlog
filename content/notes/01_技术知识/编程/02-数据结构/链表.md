## 复习入口

### 一句话理解

单向链表中，每个节点通过 next 保存下一个节点的地址，头指针保存第一个节点的地址。

### 核心要点

- 单向链表只能一个一个节点地访问。
- 删除节点时需要注意释放被删除节点。
- 删除节点时需要把下一个节点的地址填入上一个节点的 next 指针中。
- 笔记中的面试题是删除单向链表中所有小于或大于指定值的节点，并返回删除后的首节点。
- 这篇笔记关联 相关笔记。

## 单向链表
### 最小示例
```cpp
struct Node {
	int vlue;
	Node* next;
	
	// 初始化非必须不过建议带上
	explicit Node(int value, Node* next = nullptr) : value(value), next(next) {}
};
```

### 注意
- 遍历 只能一个一个节点的访问
- 删除 需要注意删除节点的释放,以及将下一个节点的地址填入上一个节点的next指针中

### 面试题
删除单向链表中所有小于(或者大于)指定值的节点, 并返回删除后的首节点(如果都小于(或者大于)返回空指针)
```cpp
struct Node {
	int vlue;
	Node* next;
	
	// 初始化非必须不过建议带上
	explicit Node(int value, Node* next = nullptr) : value(value), next(next) {}
};
```
#### 遍历
##### 前驱节点previous+当前节点啊current 双指针
		```cpp
		Node* removeLessThan(Node* head, int value) {
		    Node dummy(0, head);

		    Node* previous = &dummy;
		    Node* current = head;

		    while (current != nullptr) {
		        if (current->data < value) {
		            Node* doomed = current;

		            previous->next = current->next;
		            current = previous->next;

		            delete doomed;
		        } else {
		            previous = current;
		            current = current->next;
		        }
		    }

		    return dummy.next;
		}
		```
##### 让current永远只想待检查的前驱节点
		```cpp
		Node* removeLessThan(Node* head, int value) {
		    Node dummy(0, head);

		    Node* current = &dummy;

		    while (current->next != nullptr) {
		        if (current->next->data < value) {
		            Node* doomed = current->next;

		            current->next = doomed->next;

		            delete doomed;
		        } else {
		            current = current->next;

		    return dummy.next;
		```

##### 不适用dummy节点,单独处理头节点
		```cpp
		Node* removeLessThan(Node* head, int value) {
		    while (head != nullptr && head->data < value) {
		        Node* doomed = head;
		        head = head->next;
		        delete doomed;
		    }

		    if (head == nullptr) {
		        return nullptr;
		    }

		    Node* current = head;

		    while (current->next != nullptr) {
		        if (current->next->data < value) {
		            Node* doomed = current->next;
		            current->next = doomed->next;
		            delete doomed;
		        } else {
		            current = current->next;
		        }
		    }

		    return head;
		}
		```
##### 二级指针
		```cpp
		Node* removeLessThan(Node* head, int value) {
		    Node** link = &head;

		    while (*link != nullptr) {
		        Node* current = *link;

		        if (current->data < value) {
		            *link = current->next;
		            delete current;
		        } else {
		            link = &current->next;
		        }
		    }

		    return head;
		}
		```
#### 递归
	```cpp
	Node* removeLessThan(Node* head, int value) {
	    if (head == nullptr) {
	        return nullptr;
	    }

	    head->next = removeLessThan(head->next, value);

	    if (head->data < value) {
	        Node* next = head->next;
	        delete head;
	        return next;
	    }

	    return head;
	}
	```
#### 创建新链表
	```cpp
	Node* filterCopy(const Node* head, int value) {
	    Node dummy(0);
	    Node* tail = &dummy;

	    while (head != nullptr) {
	        if (head->data >= value) {
	            tail->next = new Node(head->data);
	            tail = tail->next;
	        }

	        head = head->next;
	    }

	    return dummy.next;
	}
```
